Adds functionality to cancelation tokens. Specifically helps for scenarios where you have the token but may not have access to the source.

Remarks

Cancelation functions can either access the internal token source or use an intermediate source. Common practice uses a temporary linked CancellationTokenSource. We use that method here. LLots of these methods only work because disposing a token source doesn't break the token.
