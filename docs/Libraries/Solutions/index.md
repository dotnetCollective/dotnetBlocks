# Solution Libraries

Solution libraries solve common problems and can be used as point solutions in your coding projects.
This is probably why you came here first!

## Libraries

- [dotNetBlocks.System](System.md) - Extends functionality in the System namespace.
- - [dotNetBlocks.System.IO](System.IO.md) - easily stream large content with minimum resources.
- [dotNetBlocks.System.Threading](System.Threading.md) - solves cancellation token problems
- [DotNetBlocks.Extensions](Extensions.md) - adds Lazy<TService> functionality to Microsoft DI system.
- [DotNetBlocks.System.Collectionns](System.Collections.md) - Generic enumeration extensions to deal with null values in collections or to ensure a collection has at least one item.
- [dotNetBlocks.System.Linq](System.Linq.md) - Wildcard search extensions for optimal wildcard searching
