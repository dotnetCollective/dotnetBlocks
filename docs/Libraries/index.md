# Libraries

# Libraries Overview

There are two categories of libraries:
1. **Blocks** with all the components to implement large enterprise solutions using the framework and patterns as explained in the 
[Design](../Design/index.md)
2. **Solution libraries** solving specific simpler problems.


# [Solution Libraries](Solutions/index.md)

- [dotNetBlocks.System](Solutions/System.md) - Extends functionality in the System namespace.
- - [dotNetBlocks.System.IO](Solutions/System.IO.md) - easily stream large content with minimum resources.
- [dotNetBlocks.System.Threading](Solutions/System.Threading.md) - solves cancellation token problems
- [DotNetBlocks.Extensions](Solutions/Extensions.md) - adds Lazy<TService> functionality to Microsoft DI system.
- [DotNetBlocks.System.Collectionns](Solutions/System.Collections.md) - Generic enumeration extensions to deal with null values in collections or to ensure a collection has at least one item.
- [dotNetBlocks.System.Linq](Solutions/System.Linq.md) - Wildcard search extensions for optimal wildcard searching


## [Block Libraries](Blocks/index.md)
- [DotNetBlocks.ServiceBus](Blocks/Servicebus.md) - Implements Service Bus functionality combining Mass Transit with an operation model to provide a rapid implementation event architecture.
- [DotNetBlocks.ServiceBus.Shared](Blocks/Servicebus.Shared.md) - Shared base interfaces and classes implementing event and message bus functionality.
- [DoNetBlocks.Business.Shared](Blocks/Business.Shared.md) - Shared based classes and interfaces for supporting business domain modelling, business entities and other business classes.
