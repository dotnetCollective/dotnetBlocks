# Block Libraries

Block libraries are the starting point for using the scalable enterprise block design.

## Libraries
- [DotNetBlocks.ServiceBus](Servicebus.md) - Implements Service Bus functionality combining Mass Transit with an operation model to provide a rapid implementation event architecture.
- [DotNetBlocks.ServiceBus.Shared](Servicebus.Shared.md) - Shared base interfaces and classes implementing event and message bus functionality.
- [DoNetBlocks.Business.Shared](Business.Shared.md) - Shared based classes and interfaces for supporting business domain modelling, business entities and other business classes.
