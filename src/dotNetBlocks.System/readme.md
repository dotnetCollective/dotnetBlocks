## Guid Extensions

Adds extensions methods to generated CombGuids and initialize existing variables with CombGuids, based on a variety or algorithms implemented in this library by RichardTallent. implementing Jimmy Nilssons CombGuid strategy for generating high performing Global Identifiers.
[RT.Comb - RIchard-Tallent](https://github.com/richardtallent/RT.Comb) This is an acceptable global dependency. The problem is well explained in the readme.
